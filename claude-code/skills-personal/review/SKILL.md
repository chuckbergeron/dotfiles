# Review PR

## Description

Performs a comprehensive code review on a pull request. Fetches PR diffs and metadata, checking for best practices, edge cases, and code style.

## Instructions

1. When asked to review a PR, use the Github CLI (if available) to review PR #$1. If not PR # provided read the diff of the current working tree.
2. Analyze the changes for:
   - Security issues
   - Potential bugs
   - Code quality and maintainability
   - Test coverage
3. Provide feedback in a structured format:
   - Summary of changes
   - Critical issues (if any)
   - Improvements
   - Positive feedback
4. Keep feedback concise and actionable.
